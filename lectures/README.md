# Lecture system

The system built up during the lectures: a reaction-time meter on the Svarog SoC
(RGB PWM with a FIFO, timer, LFSR, buzzer, VGA leaderboard, ADXL362 through
**software** SPI over GPIO). One git tag per lecture. Nothing is here yet.

Rule for this folder: the lecture system must **not** contain a solution to any lab
(GPIO, 7-segment display, UART with FIFO, interrupts, SPI master + ADXL362).
